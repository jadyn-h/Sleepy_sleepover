# sleepy
Funmi, Jadyn, and Ray's project for Sleepover!

Our project is called Sleepy and it's a game that is hosted in a website that explores how the events of the day affect your dreams! Sleepover's theme was 'In Your Dreams' so we created a visual novel that takes a user through some choices in their day and those choices are reflected in the dream mini games in the sleep portion.
The visual novel is contained in a website and within the visual novel, there are 4 playable mini games based on the user's choices.

This project features HTML, CSS, Javascript, RenPY and the minigames were made in Gamemaker.

Stack:
HTML/CSS - Website
Ren'Py - Visual novel
Game Maker - Games
Javascript - Integration

- Funmi made the visual novel in RenPy
- Ray made the mini games in Gamemaker
- Jadyn made the website for Sleepy

Throughout the process, we had issues with getting Gamemaker to work, properly commiting to the repo and dealing with errors in RenPy and the webpage. We were able to solve all of these issues by asking each other within the group and asking other people from Sleepover for help!
