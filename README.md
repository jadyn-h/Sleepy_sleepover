# sleepy
Funmi, Jadyn, and Ray's project for Sleepover!

Our project is a game that is hosted in a website that explores how the events of the day affect your dreams!
The visual novel is contained in a website and within the visual novel, there are 4 playable mini games based on the user's choices.

This project features HTML, CSS, Javascript, RenPY and the minigames were made in Gamemaker.

- Funmi made the visual novel in RenPy
- Ray made the mini games in Gamemaker
- Jadyn made the website for Sleepy
